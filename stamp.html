Đóng dấu PL02 tự động bằng Mistral AI (HTML tĩnh)

Chạy hoàn toàn trong trình duyệt — không cần server. Đọc & phân loại từng trang PDF scan, typewriter mã PL02 (màu đỏ) vào góc trên-trái trang đầu mỗi văn bản. KHÔNG tách file PDF.

Lưu ý: Bản tĩnh chạy trực tiếp trong trình duyệt nên cần internet để tải thư viện pdf.js/pdf-lib từ CDN và gọi API Mistral (api.mistral.ai hỗ trợ CORS). Nhãn đóng dấu được chèn dưới dạng chú thích PDF (FreeText annotation), không vẽ chết lên nội dung trang — vì vậy sau khi tải file kết quả, có thể mở bằng Foxit Reader (hoặc Adobe Acrobat), dùng công cụ Typewriter/Comment, bấm đúp vào ô nhãn để sửa lại nếu AI phân loại sai, mà không cần chạy lại toàn bộ quy trình.

1. Cấu hình Mistral AI

Gói Free giới hạn ~1 request/giây, nên giữ độ trễ 3 giây/trang. Key chỉ gọi trực tiếp lên Mistral từ trình duyệt của bạn.
Gói trả phí có thể đặt 0.

2. Chọn file PDF

Kéo & thả file PDF vào đây
hoặc bấm để chọn file từ máy tính

3. Tuỳ chọn đóng dấu

Ở chế độ này công cụ KHÔNG gọi API Mistral, không cần API key — chỉ chèn đúng văn bản bạn nhập vào các trang chọn bên dưới, dưới dạng chú thích có thể sửa lại bằng Foxit/Acrobat. Lưu ý: chữ có dấu tiếng Việt hiển thị chính xác nhất khi mở bằng Foxit Reader/Adobe Acrobat; một số trình xem PDF đơn giản khác có thể hiển thị sai dấu.
Đánh số trang bắt đầu từ 1, có thể liệt kê cách nhau bằng dấu phẩy và/hoặc khoảng bằng dấu gạch ngang.
